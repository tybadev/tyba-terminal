## Abrir

<Tabs>
<Tab title="macOS">
`⌘F` abre y cierra la búsqueda del panel activo.
</Tab>
<Tab title="Windows y Linux">
`Ctrl+Shift+F` abre y cierra la búsqueda del panel activo.
</Tab>
</Tabs>

También con **botón derecho en la terminal** → *Search in terminal*.

La caja aparece en la esquina superior derecha del panel. La búsqueda es **del panel** — cada terminal tiene su propio historial, y la búsqueda solo ve ese.

## Navegar

| Tecla | Qué hace |
| --- | --- |
| `↵` | Siguiente resultado |
| `⇧↵` | Resultado anterior |
| `Esc` | Cierra y devuelve el foco a la terminal |

Las flechas `▲` `▼` de la caja hacen lo mismo que `⇧↵` y `↵`.

Mientras escribes, TYBA ya va marcando el primer resultado — no hace falta pulsar Enter para ver dónde coincidió.

## El contador

A la derecha del campo:

| Lo que aparece | Qué significa |
| --- | --- |
| `3/17` | Estás en el tercero de diecisiete. |
| **Sin resultados** | El término no existe en el scrollback de este panel. |
| *(vacío)* | Todavía no escribiste nada. |

Los resultados se pintan con **los colores de tu tema**: todos los matches con una marcación, y el activo con otra. Si cambias de tema, la búsqueda cambia con él.

## Ya viene rellenada

Si tenías algo **seleccionado** al abrir la búsqueda, la query nace con ese texto — ya seleccionado en el campo, listo para reemplazarse si no era lo que querías.

<Note>
Esto solo vale para selecciones **de una sola línea**. Una selección con salto de línea no rellena nada: la búsqueda es de texto corrido, y una query de tres líneas nunca encontraría nada.
</Note>

El flujo que esto desbloquea: ves un hash de commit, un ID de request o un nombre de archivo en el output, le das dos clics, `⌘F`, `↵` — y estás recorriendo todas las otras veces en que apareció.

## El límite de 10.000 líneas

La terminal guarda **10.000 líneas** de scrollback. Fijo.

<Warning>
**Lo que pasó de esas 10.000 líneas ya no existe.** La búsqueda no lo encuentra porque no hay nada que encontrar — la línea se descartó cuando llegó la 10.001.
</Warning>

Este no es un número que puedas subir: no hay campo en Settings, ni preferencia escondida, ni archivo para editar. Un `cat` de un log gigante, un build verboso, un agente volcando un diff — cualquiera de ellos empuja afuera lo que estaba antes.

Si lo que necesitas encontrar es de hace media hora y mil comandos, el lugar donde buscar no es la búsqueda de la terminal — es el archivo, el log o `git`.

## Lo que la búsqueda no ve

| | |
| --- | --- |
| **Otros paneles** | Cada panel tiene su propio buffer. La búsqueda es solo del panel activo. |
| **Sesiones cerradas** | Cerraste el panel, se fue. |
| **El historial de antes de reabrir la app** | El proceso local no sobrevive al cierre de TYBA: la sesión vuelve, el buffer no. **Los paneles SSH son la excepción** — la shell remota sigue viva y el reattach trae el buffer consigo ([persistencia](/es/ssh/persistencia)). |
| **Regex** | No hay toggle de regex, "solo palabra entera" ni "distinguir mayúsculas" en la caja. Es una búsqueda de texto. |
