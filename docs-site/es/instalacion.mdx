Los binarios de la versión actual están en [Releases](https://github.com/tybadev/tyba-terminal/releases).

<Tabs>
<Tab title="macOS">
**macOS 11 o superior.** Descarga el `.dmg` de tu chip — Apple Silicon o Intel.

Firmado y notarizado: abre sin aviso de Gatekeeper.
</Tab>

<Tab title="Linux">
Descarga el `.deb`, el `.rpm` o el `.AppImage`:

```bash
sudo apt install ./Tyba_0.1.2_amd64.deb     # Debian / Ubuntu
sudo dnf install ./Tyba-0.1.2-1.x86_64.rpm  # Fedora
yay -S tyba-bin                             # Arch (AUR)
```

<Warning>
**`bubblewrap` es obligatorio, no sugerido.** Sin él, el core se niega a crear sesiones de agente y TYBA queda como una terminal cualquiera.

El `.deb`, el `.rpm` y el paquete del AUR ya lo instalan. Con el AppImage, instálalo tú: `apt install bubblewrap`.
</Warning>

Si tu distribución deshabilita los namespaces de usuario no privilegiados — algunos kernels endurecidos, o Debian con `kernel.unprivileged_userns_clone=0` — las sesiones de agente se rechazan con un mensaje que explica el motivo. El sandbox nunca se degrada en silencio.
</Tab>

<Tab title="Windows">
Descarga el `.exe` o el `.msi`:

| Archivo | Cuándo usarlo |
| --- | --- |
| `.exe` | Para la mayoría — clic e instalar |
| `.msi` | Instalación gestionada o silenciosa |

<Warning>
**El instalador todavía no está firmado.** SmartScreen va a mostrar *"Windows protegió tu PC"*. Haz clic en **Más información → Ejecutar de todas formas**. La firma llega cuando el certificado esté en su lugar.
</Warning>

La jaula de agente llegó a Windows en la 0.1.2. Como en las demás plataformas, es fail-closed: si no puede aplicarse, la sesión se rechaza en vez de correr sin jaula.

<Warning>
**La garantía de lectura en Windows es menor que en macOS y Linux.** La escritura se contiene igual, pero la lectura está abierta por defecto, con una lista de secretos conocidos cerrada. En la práctica: el `.env` de otros proyectos tuyos y otros repositorios de tu máquina **son legibles por el agente**.

Lee [Plataformas](/es/seguridad/plataformas) antes de decidir si esto te sirve.
</Warning>
</Tab>
</Tabs>

## Instala un agente

<Warning>
**Los agentes no vienen incluidos.** TYBA orquesta Claude Code y Codex — no los embebe.
</Warning>

Instala al menos uno:

- [Claude Code](https://claude.com/claude-code)
- [Codex](https://developers.openai.com/codex/cli)

TYBA encuentra a los dos por tu `PATH`. Si no hay ninguno instalado, puedes usar la terminal, pero no crear una sesión de agente.

## Necesitas un repositorio git

Las sesiones de agente corren en worktrees, y un worktree es un concepto de git. Una carpeta que no es un repositorio no sirve.

## Compruébalo

Abre TYBA y crea una sesión de agente. Si levanta, los tres prerrequisitos están en pie: el agente está en el `PATH`, el sandbox se aplica, y el directorio es un repositorio.

Si algo falta, el mensaje dice cuál — TYBA falla explicando, no en silencio.
